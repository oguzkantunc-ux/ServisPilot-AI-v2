# ServisPilot AI v2

Gerçek yol geometrisi, TomTom trafik destekli süre/mesafe ve canlı trafik katmanı kullanan Next.js uygulaması.

## Vercel değişkenleri

- `TOMTOM_API_KEY`
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

Supabase tabloları: `passengers`, `destinations`, `vehicles`, `drivers`.

```bash
npm install
npm run dev
```
